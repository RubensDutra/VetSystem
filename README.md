# 🐾 VetSystem

Sistema backend para gerenciamento de uma clínica veterinária, desenvolvido em **Java** como projeto de estudo e portfólio para preparação para uma vaga de estágio Backend Java.

## 🎯 Objetivo

O VetSystem tem como objetivo permitir o gerenciamento das principais operações de uma clínica veterinária, incluindo:

* Cadastro de clientes
* Cadastro de animais
* Cadastro de veterinários
* Agendamento de consultas
* Histórico médico dos animais
* Controle de usuários
